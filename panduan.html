📝 Korektor LJK

Instal · Pakai · Selesai — semua dalam satu halaman

🎯Apa Ini?
  • Guru memfoto lembar jawaban siswa → aplikasi mendeteksi bulatan otomatis → nilai langsung jadi
  • Murni HTML + JavaScript — tanpa framework, tanpa biaya
  • Format LJK: 40 soal 4 pilihan (A–D) 4 blok à 10
⚡Versi Offline — Paling Cepat
  • Tanpa instalasi: buka local.html langsung di browser
  • Data tersimpan di perangkat sendiri (localStorage) — privat
  • Identitas sekolah bisa diedit pengguna (tombol 🏫 di tab Kunci)
  • Sudah termasuk Export CSV, Backup, dan Restore
🚀 Buka Aplikasi Offline
🏫Instal Versi Sekolah (± 5 Menit)
  1. Buat Spreadsheet baru → menu Extensions → Apps Script
  2. Salin kode Code.gs & Index.html dari halaman Installer
  3. Paste: Code.gs ke file .gs; buat file HTML bernama Index untuk yang satunya
  4. Deploy → New deployment → Web app — Execute as: Me, Access: Anyone
  5. Buka URL /exec dari HP → selesai! 🎉
⚠️ Jika kode pernah diubah: Deploy → Manage deployments → ✏️ → New version → Deploy agar perubahan tampil di URL /exec.
📦 Buka Installer
📖Cara Pakai
  1. 🔑 Kunci: atur jenis ujian, semester (Ganjil/Genap), tahun pelajaran, jumlah soal → isi kunci → simpan
  2. 🖨 Template: klik Buat Template LJK → ⬇️ Unduh PNG → cetak A4 (skala 100%) → fotokopi
  3. 📸 Koreksi: foto lembar siswa → ketuk 4 sudut kotak blok 1–10 → Deteksi → ulangi blok 11–20, 21–30, 31–40 (satu foto untuk semua blok)
  4. ✅ Periksa hasil (ketuk untuk memperbaiki) → isi nama → 💾 Simpan
  5. 📊 Hasil: rekap nilai + ekspor (Sheets / CSV)
💡 Tips foto akurat: tegak lurus dari atas · cahaya merata tanpa bayangan · bulatan dihitam pekat & penuh dengan pulpen hitam · ketuk sudut tepat di pojok kotak blok (bukan huruf A–D / nomor soal).
