🚀 5 Langkah Instalasi

  1. Buat Spreadsheet baru di sheets.google.com → menu Extensions → Apps Script
  2. Hapus isi editor, tempel kode Code.gs (klik 📋 Salin pada kartu pertama)
  3. Klik ＋ → HTML, beri nama Index (harus persis, tanpa .html), hapus isinya, tempel kode Index.html (kartu kedua)
  4. Simpan (Ctrl+S) → Deploy → New deployment → Web app
    Execute as: Me · Who has access: Anyone → Deploy → izinkan akses
  5. Salin URL Web App (berakhiran /exec) → buka dari HP → selesai 🎉
⚠️ Jika kode pernah diubah: Deploy → Manage deployments → ✏️ → New version → Deploy agar perubahan tampil di URL /exec.
