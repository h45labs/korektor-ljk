tentang

Aplikasi koreksi lembar jawaban ujian pilihan ganda lewat kamera HP. Murni HTML + JavaScript tanpa framework, berjalan di Google Apps Script (tanpa server, tanpa biaya) atau sepenuhnya offline via localStorage.

Dikembangkan oleh HijraH45 · untuk penilaian di MTS Darul Falah, Citeureup — Bogor.

dua versi

🏫
Versi Sekolah — Code.gs + Index.html
Data terpusat di Google Sheets, multi-guru, deploy sebagai Web App.
⚡
Versi Offline — local.html
Data di localStorage perangkat. Buka langsung dari browser, tanpa internet, identitas lembaga bisa diedit pengguna.

fitur

📷
Scan via kameraFoto langsung atau unggah dari galeri; satu foto untuk semua blok.
🧮

Rekap & eksporRekap nilai di aplikasi; Sheets (sekolah) atau Export CSV (offline).
💾
Backup / RestoreVersi offline menyertakan cadangan JSON lengkap dengan kunci & identitas.

instalasi versi sekolah

1
Buat Spreadsheet baru → menu Extensions → Apps Script
2
Tempel Code.gs (backend), lalu buat file HTML bernama Index dan tempel Index.html (frontend)
3
Deploy → New deployment → Web app — Execute as: Me, Access: Anyone
4
Salin URL /exec → buka dari HP → selesai
⚠️ Ingat: setelah mengubah kode, wajib Deploy → Manage deployments → New version, agar perubahan muncul di URL /exec.

versi offline

Cukup buka local.html — tidak perlu spreadsheet, tidak perlu deploy. Favicon, kamera (via https), dan seluruh fitur bekerja langsung.

troubleshooting

GejalaSolusi

Bulatan kosong terbacaNaikkan Sensitivitas (≈0.55) / ketuk sudut tepat di pojok kotak
Kamera tidak munculWajib https (GitHub Pages ✅); atau pakai 📁 Unggah Foto
Identitas tertutup kopGunakan versi terbaru (jarak 26px, kop tanpa border)
Kode tidak berubahBelum deploy new version
Favicon tak tampil (Apps Script)Normal — iframe Google; bekerja ✅ di GitHub Pages

keterbatasan

◦ Hanya mendukung template bawaan (bulatan tengah sel, 10 soal/blok) — LJK sel-kotak/tanda-silang tidak didukung.
◦ Uraian/essay tidak dikoreksi otomatis.
◦ Kemiringan foto aman sampai ±10–15° (tanpa koreksi perspektif penuh).
◦ Versi offline: data terikat satu browser — biasakan Backup/Export tiap selesai.
